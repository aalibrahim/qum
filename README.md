# قُم (Qum) website

The public pages for Qum, a free Arabic Fajr alarm for iPhone: the landing page (`index.html`), the privacy policy (`privacy.html`) and support (`support.html`).

Static files, no build step and no third-party requests. The Quran text in `index.html` is filled in from the app's verse dataset by `Tools/build_site.py` in the app repository; do not edit it by hand.

Quran text: Tanzil Project (tanzil.net), reproduced verbatim. Font: Amiri Quran, SIL Open Font License (see `assets/AmiriQuran-OFL.txt`).
